- **$\Omega \subset \mathbb{R}^2$ é o domínio espacial (coordenadas $x$ e $y$):**  
  $\Omega$ representa a região física da chapa sólida no plano $xy$. No nosso caso com 3 furos, $\Omega$ é o quadrado unitário $[0, 1] \times [0, 1]$ **subtraído dos 3 círculos**:
  $$\Omega = \left\{ (x, y) \in [0, 1] \times [0, 1] \;\middle|\; (x - x_k)^2 + (y - y_k)^2 > r_k^2, \; \forall k \in \{1, 2, 3\} \right\}$$
- **$(0, T] \subset \mathbb{R}$ é o domínio temporal (coordenada $t$):**  
  É o intervalo contínuo de tempo em que a difusão ocorre, partindo do repouso $t=0$ até o tempo final $T_{\text{max}} = 1{,}0$.
- **O produto cartesiano $\Omega \times (0, T]$ (Cilindro Espaço-Temporal):**  
  Significa que a EDP do calor deve ser satisfeita para **todo ponto espacial $(x, y) \in \Omega$ em cada instante de tempo $t \in (0, T]$**.

### 2. A Física do Problema com os 3 Furos Circulares

Criamos um diagrama esquemático dedicado mostrando a geometria exata:

```
 y=1.0  ┌─────────────────── Fonte de Calor: u(x, 1, t) = 1.0 ───────────────────┐
        │                                                                        │
        │                             [Furo 3]                                  │
        │                           (0.50, 0.70)                                │
        │                            r = 0.12                                   │
        │                          (u = 0.0)                                    │
        │                                                                        │
        │                                                                        │
        │          [Furo 1]                                [Furo 2]              │
        │        (0.30, 0.30)                            (0.70, 0.30)            │
        │         r = 0.12                                r = 0.12               │
        │       (u = 0.0)                               (u = 0.0)                │
        │                                                                        │
 y=0.0  └─────────────────── Fonte de Calor: u(x, 0, t) = 1.0 ───────────────────┘
       x=0.0                                                                   x=1.0
```

- **Dimensões e Centros:**
  - $\mathcal{H}_1$: Centro $(0{,}30;\, 0{,}30)$, raio $r=0{,}12$
  - $\mathcal{H}_2$: Centro $(0{,}70;\, 0{,}30)$, raio $r=0{,}12$
  - $\mathcal{H}_3$: Centro $(0{,}50;\, 0{,}70)$, raio $r=0{,}12$
- **Dinâmica Térmica:**
  1. O sólido começa todo frio: $u(x, y, 0) = 0$ em toda a chapa $\Omega$.
  2. As 4 paredes exteriores ($x=0, x=1, y=0, y=1$) são aquecidas continuamente a $u = 1{,}0$.
  3. Os 3 furos funcionam como **canais de refrigeração mantidos a $u = 0{,}0$** (sumidouros térmicos), "sugando" o calor que entra pelas bordas e gerando fortes zonas de gradiente térmico em torno de si.
